# Тест тока (STM32U585 + Waveshare 2.7" HAT V2)

Прошивка `demo/eink_power_test.c` вместо демо прогоняет 63 шага; в каждом одна комбинация режимов.
На экране рядом с картинкой написано, что проверяется (тот же текст идёт в UART, EINK_DIAG=ON).
Замерьте ток мультиметром, пока шаг идёт, и запишите в таблицу.

## Сборка

```
cmake --preset Release -DEINK_POWER_TEST=ON        # из каталога eink_u585
# необязательно: -DPWR_DWELL_STATIC_S=15 -DPWR_DWELL_DYN_S=30 -DPWR_TEST_BW_KEEP=ON
```
Собирайте Release (-Os): в Debug (-O0) процессор в динамике считает кадр заметно дольше.
Изменений в CubeMX не нужно (LPTIM1, LSI и EXTI2 настраиваются из `Core/Src/eink_pwr.c`).
Подмножество шагов: `-DPWR_GROUPS=1|2|4` (маска: STATIC, DYN-4G, DYN-1B), `-DPWR_FIRST_STEP=N -DPWR_LAST_STEP=M`
(полезно, если при переключении диапазона мультиметра плата перезагрузилась).

## Подготовка измерения

* Мультиметр в разрыв питания платы (3V3 МК + HAT). Если можно, меряйте отдельно HAT и МК.
* Отладчик (ST-Link) отключить, питать только через мультиметр, перед стартом передёрнуть питание:
  при подключённом отладчике токи Sleep/Stop 2 завышены.
* Диапазон выбирайте заранее: Stop 2 - мкА, RUN и динамика - мА (автодиапазон может сбросить МК).
* На время замера USART1/USART2 выключены (тактирование снято), UART молчит.

## Шаги

| Группа | Перебор | Шагов | Длительность замера |
|---|---|---|---|
| STATIC | панель {аналог ВКЛ, аналог ВЫКЛ, deep sleep} x линии {ACTIVE, HIGH, LOW, ANALOG} x МК {RUN, SLEEP, STOP2} | 36 | 15 с (аналог ВКЛ - не более 20 с) |
| DYN-4G | питание {KEEP, CYCLE} x линии в паузах {ACTIVE, HIGH, ANALOG} x МК в паузах {RUN, SLEEP, STOP2} | 18 | 30 с |
| DYN-1B | линии в паузах x МК в паузах | 9 | 30 с |

Каждый шаг начинается с полного обновления с новой подписью (экран мигает, 3-6 с), замер - после него.
Весь прогон около 30 минут; по окончании на экране `TEST DONE`, панель в deep sleep.

Расшифровка:

* **Аналог ВКЛ/ВЫКЛ** - 0xC4 (остаётся после обновления) / команда power off 0x83. **DEEP SLEEP** - команда 0x10.
  Аналог панели долго включённым держать нельзя (руководство Waveshare, п. 3 Notes), поэтому шаг ограничен.
* **ACTIVE** - SPI1 включён, линии как оставила библиотека (в журнале `[HOLD]` печатается уровень DC).
  **HIGH / LOW** - SPI1 выключен и без тактирования, SCK/MOSI/DC в 1 / в 0, CS и RST в 1.
  **ANALOG** - SPI1 выключен, все шесть линий (в статике и BUSY) в analog.
  В динамике линии переключаются только на время ожидания волны; CS и RST остаются выходами
  (библиотека держит RST низким в импульсе сброса).
* **RUN** - цикл на HSI 16 МГц; **SLEEP** - WFI, SysTick остановлен; **STOP2** - Stop 2, будильник LPTIM1 (LSI),
  в динамике будит ещё и спад BUSY; паузы короче 3 мс в STOP2 проводятся в Sleep.
* **KEEP / CYCLE** (4 gray) - аналог остаётся включённым между проходами / включается и выключается каждый раз.
  В 1-bit штатно CYCLE (в библиотеке KEEP там не проверен; `-DPWR_TEST_BW_KEEP=ON` включит его).
* Динамика - чистые частичные обновления подряд, без автоматических полных (`epd4g_set_partials_before_full(0,0)`).
  Периодическое полное обновление в замер не входит, учтите его отдельно.

## Как выбрать режим

1. Для статики возьмите минимальный ток по строкам (панель x линии x МК), для динамики - по строкам DYN.
2. В конце каждого динамического шага в UART печатается `avg ... ms per update`. Энергия на одно
   обновление = I x U x время обновления: KEEP быстрее, но ток выше, сравнивать нужно именно её.
3. Средний ток навигатора = доля времени динамики x I_dyn + остальное x I_static (+ полное обновление).

Что стоит проверить в первую очередь: сравнить HIGH / LOW / ANALOG и ACTIVE (в HAT стоит транслятор
TXS0108E, у него есть встроенные подтяжки к питанию; линия, удерживаемая в 0, может тянуть сотни мкА).
